## Integration dependencies outside ownership

1. **Rename apply: src/editor/document.rs and src/ui/language_dialog.rs.** Capture checked version and old identifier in PromptKind::Rename/Prompt::rename. On confirmation, before touching selection or undo, require the same tab, writable state, exact version, valid nonoverlapping ranges and the old text in every range. Apply replacements as one undoable transaction or refuse atomically. Suggested core API: rename_checked(expected_version, old_name, ranges, new_name) -> Result<_, RenameError>. Extend the prompt constructor and update this branch's host call together. This branch retains its current three-argument constructor to compile independently. Prompt-opening validation cannot secure confirmation after an intervening reload/edit.
2. **WXME save callers: src/app.rs, files/shell owner.** Replace synchronous write_wxme calls with begin_write_wxme(app, path, text_snapshot, images_snapshot) -> Result<WxmeWriteTask, String>. Keep the task, tab ID, captured version/path, save purpose (ordinary/autosave/Save As/close/quit), and disk-conflict snapshot. Poll try_result after racket_ui::poll; only successful completion may update saved state for that snapshot. Preserve intervening edits, serialize writes to one destination, retain conflict checks, postpone close/quit until success, and surface failures once. Dropping the task does not cancel a disk write in progress. Remove the synchronous adapter after migration. WXME serialization tests do not establish completion of this caller integration.
