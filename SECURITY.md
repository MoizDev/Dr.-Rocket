# Security

Please report security problems privately, not in a public issue: use
[Report a vulnerability](https://github.com/MoizDev/Dr.-Rocket/security/advisories/new) on
GitHub. Include what you found, how to reproduce it, and the version you tested
(About Dr. Rocket, or Report a Problem… in the ☰ menu, shows it).

Fixes ship in a new release, which existing installs pick up through automatic updates.
Updates are signed; see [docs/signed-updates.md](docs/signed-updates.md).
