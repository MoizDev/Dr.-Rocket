Visualizer improvements:
- Work done on the way (like `(random 100)` or `(sub1 n)`) is highlighted in the editor in a second colour, with its value after the line.
- Every call waiting on the stack shows what it will do with the answer, e.g. `(bst-insert 37 ( ••• ))`; the answer lands in that slot when the call below returns.
- Redesigned call cards: running / waiting / returning states, a decision diamond with the answer on question steps, and a compact top-level capsule.
- Editor notes never cover code, and horizontal scrolling reaches the end of them.
