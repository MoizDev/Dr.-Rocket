- **Move files by dragging:** drag a file or folder in the file tree onto a folder to move it there, or onto the project name (or the empty space below the files) to move it to the top. The folder it will land in is outlined, a closed folder opens if you hold the drag over it, and the tree scrolls when you drag near its top or bottom. Open tabs follow the file to its new place. Press Escape to cancel.
- **Choose Language settings apply when you Run:** "Print true/false/empty instead of #true/#false/'()" now changes what Interactions shows (results, what you type, and check-expect messages), and so do the printing style, fraction style, sharing and newline settings. The visualizer follows them too.
- **Indentation matches DrRacket:** Tab, Enter and Reindent All (now ⌘I) indent code exactly as DrRacket does. A line length guide shows where long lines start (column 102 by default; change it or turn it off in Settings).
