- **Your work is safer:** if a file changes on disk while you have unsaved edits, Dr. Rocket keeps both versions instead of overwriting either one. Renaming a file never replaces another one, files keep their encoding and line endings, and a damaged settings file is recovered instead of reset.
- **Faster with big files:** reindenting, highlighting and editing very long lines are much faster. Project search and folder watching run in the background, and saving a file with images no longer freezes the editor.
- **Editing fixes:** undo, comment toggling, quotes, Rename, Vim mode and several keyboard shortcuts now behave as expected.
- **Running programs:** Stop ends a program cleanly, huge output or very deep recursion no longer breaks Interactions, and Interactions keeps working after read and runtime errors.
- **Visualizer and terminal:** the Visualizer stays responsive during long recordings. The terminal handles control keys, copy and paste correctly.
- **Safer updates:** each update is checked against the signed release it belongs to before it's installed.
