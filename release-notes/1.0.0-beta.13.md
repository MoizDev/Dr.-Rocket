- **No more lost work when quitting on macOS:** quitting from the Dock, or logging out or restarting your Mac, now asks about unsaved files first, just like ⌘Q.
- **Signed updates:** automatic updates are checked against Dr. Rocket's release signature before they're downloaded and again before they're installed, so only official releases can be installed.
- **Safer saving:** saves go to a new temporary file that then replaces the old one, so a save can't be redirected to another file. Files that open read-only (because they contain DrRacket boxes Dr. Rocket can't edit yet) stay unsaveable even after you edit them, so they're never damaged.
- **Sturdier Racket connection:** if checking a program takes longer than 30 seconds, Dr. Rocket restarts its background Racket and carries on instead of waiting forever, and runaway output from Racket can no longer use up memory.
