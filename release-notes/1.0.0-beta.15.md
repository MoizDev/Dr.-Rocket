- **Tests that hit an error now fail:** a `check-expect` whose expression raises an error (calling a function with the wrong number of arguments, dividing by zero) was counted as passed. It now counts as failed, with the error shown under it, like DrRacket. The problems icon at the bottom of the window also turns red for failed tests.
- **Closing brackets:** typing `)` adds one when an outer bracket still needs closing, instead of stepping over the `)` after the caret. In `(+ (* x 2|)` it now gives `(+ (* x 2))`.
