**Vim mode.** Turn it on in Settings > Keybindings or with "Toggle Vim Mode". Normal, insert and visual modes with Neovim's operators, motions, text objects, registers, macros and `.`; Space as the leader with a which-key popup (Space e toggles the sidebar, Space r r runs, Space r v visualizes); `:` opens a command menu (`:w`, `:q`, `:wq`, `:%s/old/new/g`, `:Visualize`...); insert-mode keys (Ctrl-W, Ctrl-U, Ctrl-T/Ctrl-D, Ctrl-R, Ctrl-O); relative line numbers; yanked text flashes and goes to the system clipboard.

**Visualizer.** Real trees, explanations in plain words with coloured object chips, a note of each step's values beside its code, step over / back over / out (Shift + arrows), and a recursion graph as the timeline.

**Editor.**
- Zoom (Cmd + / -) is per file.
- Ctrl+Tab moves between file tabs.
- Shift+Cmd+L selects all occurrences.
- Test results show as gutter ticks, with failures inline.
- Clicks place the caret instantly.
- Cmd+P shows file names first.
- Every function call is coloured blue.
