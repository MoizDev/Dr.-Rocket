- **What's New:** after an update, the release notes open in their own tab next to your projects. Close it like any tab, or reopen it any time with What's New in the ☰ menu (the Dr. Rocket menu on macOS) or the command palette.
- **Visualizer:** a new call's argument values ride its connector down into the new card, and the card receiving a returned value lights up green as the value lands (the top level too).
- **Visualizer:** closures and local functions get their own cards, showing the variables they use from around them, like the `n` in the function `(make-adder 5)` returns.
