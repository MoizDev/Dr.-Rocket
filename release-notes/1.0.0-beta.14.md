- **Problems list:** click the error counter in the editor's top-right corner to see every error, warning and failed test in the file. Click one to jump to it, or open the Problems panel from the bottom of the list. An error that both Run and the background check report now counts once.
- **Reindent with Style Guide (⇧⌘I):** lays out your code the way the course style guide does: long lines are broken in the right places and everything is reindented. Forms with unmatched brackets are left alone. It's in the Racket menu and the editor's right-click menu, and one ⌘Z undoes it.
- **Your caret stays in the code when you Run:** Run no longer moves your typing into Interactions. Press ⌘2 (or click Interactions) to type an expression there, and ⌘1 to go back. When the editor isn't focused it shows a dim outline where your caret is, so it never looks lost.
- **Brackets around a selection keep it selected:** select `HELLO` and type `(` to get `(HELLO)` with `HELLO` still selected, ready to retype or wrap again. Works with `[`, `{` and `"` too.
- **Match closing brackets setting:** typing `)` inside `[` types `]`, like DrRacket. You can now turn that off on its own in Settings.
- **Saving files that moved:** if you move or rename a file (or its folder) in Finder while it's open, Dr. Rocket follows it and saves to its new place. If it was deleted, saving asks where to save it instead of failing, and autosave stops repeating the same error.
