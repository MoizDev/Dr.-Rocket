**Automatic updates.** Dr. Rocket now checks doctorocket.com for new versions, downloads them in the background, and installs them when you quit. Click **Restart to Update** in the status bar to switch right away. About Dr. Rocket has a switch to turn this off and a Check for Updates button. This version has to be downloaded by hand once; every release after it arrives on its own.

**Memory limit.** A program that uses more than its memory limit (256 MB by default, like DrRacket) now pauses instead of being killed. The Interactions panel asks whether to keep going: **Keep Going** resumes it right where it was with double the limit, **Stop** ends it. The status bar shows how much memory the running program uses. Change the limit in Settings > Racket.
